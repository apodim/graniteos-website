About GraniteOS

GraniteOS is an innovative operating system simulator developed using GDevelop, a powerful no-code/low-code game and app development engine. This project showcases the versatility and capabilities of GDevelop beyond traditional game development, demonstrating how modern development tools can be used to create engaging and interactive software experiences.
