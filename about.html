About GraniteOS

Innovation through open-source development

Our Mission

GraniteOS is dedicated to creating a free, engaging, and accessible operating system simulator that empowers users and developers alike. We believe in the power of open-source software and community-driven innovation.

Our mission is to demonstrate that with the right tools and community support, it's possible to build sophisticated, interactive simulations that provide an immersive and educational experience while remaining completely free and open.

Our Story

GraniteOS began as a passion project to showcase the versatility of GDevelop, a powerful no-code/low-code development engine typically associated with game development. A small team of developers recognized that GDevelop's capabilities extended far beyond games and decided to create an interactive operating system simulator to prove it.

What started as an experimental proof of concept has evolved into a fully-functional operating system simulator with thousands of users worldwide who enjoy exploring the experience. Today, GraniteOS continues to grow and improve through contributions from our vibrant community.

Key Milestones

  • June 2022: Initial concept development begins
  • December 2022: First alpha release (v0.1)
  • June 2023: First stable release (v1.0) with 5,000+ downloads
  • January 2024: Major v2.0 release with complete UI redesign
  • May 2024: Current v2.1 release with 50,000+ active users

Technology Stack

GraniteOS Simulator is built on a modern, efficient technology stack that combines proven technologies with innovative solutions.

Core Components

  • Engine: GDevelop (for simulator development)
  • Frontend: Modern web technologies (HTML5, CSS3, JavaScript)
  • Scripting: GDevelop's visual scripting and JavaScript events
  • Graphics: WebGL for smooth rendering and animations
  • Storage: Local storage for simulator data and preferences
  • Distribution: Cross-platform desktop applications (Windows .exe/.zip, macOS .zip, Linux .AppImage)
