What You Get

GraniteOS Simulator is a standalone application - no installation to your OS required

Simply download, extract (if needed), and run the application to start exploring the simulated environment!

Quick Start

  • Windows: Run the .exe or extract and run from .zip
  • macOS: Extract the .zip and open the application
  • Linux: Make the .AppImage executable and double-click to run

Quick Start Guide

Step 1: Download

Choose the appropriate download for your operating system from the options above (Windows .exe/.zip, macOS .zip, or Linux .AppImage).

Step 2: Install/Extract

Windows (.exe): Run the installer and follow the prompts. Windows (.zip): Extract to any folder. macOS & Linux: Extract and double-click the application file.

Step 3: Launch the Simulator

Once installed or extracted, simply open the GraniteOS Simulator application. It will launch as a window on your desktop.

Step 4: Explore

Start exploring the simulated operating system! Interact with the desktop, applications, and features to experience the full simulator.

Step 5: Customize

Adjust settings and preferences within the simulator to personalize your experience.
